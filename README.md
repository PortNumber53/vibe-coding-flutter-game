# vibe-coding-flutter-game
Just vibe coding a mobile game using flutter, and Go


# Steps

## Install Flutter

Using "https://medium.com/@rajgadhiya011/how-to-setup-flutter-on-arch-linux-with-android-sdk-a-step-by-step-guide-f40450b55669"

1. Install Flutter: `yay -Sy flutter` and pick `jdk17-openjdk`
2. Install more packages:
```
yay -Sy android-sdk android-sdk-build-tools android-sdk-cmdline-tools-latest android-platform android-sdk-platform-tools
```
